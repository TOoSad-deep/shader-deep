# Insight：想法与讨论记录

这里保存项目探索过程中的想法、问题、备选方案和讨论结论。内容可以暂不实施，也可以在后续证据出现后调整或放弃。

**本目录不是实施计划、待办清单或当前能力说明。记录一个 idea，不代表已经采纳，也不授权自动修改代码。** 是否实施、实施范围和验收方式，需要在具体任务中另行确定。

## 记录方式

- 建议文件名：`YYYY-MM-DD-主题.md`。
- 写明讨论日期、状态、适用目标，以及仍未解决的问题。
- 区分当前源码事实、讨论倾向、备选方案与待验证假设。
- 架构图、字段和表设计默认是概念草案；只有经过明确实施与验证，才能描述为已实现。
- 如果某个想法进入实施阶段，在原记录中链接对应设计、任务或交付证据，保留原始讨论背景。
