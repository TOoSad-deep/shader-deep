# 分析报告

目标: neon_frame_main 霓虹圆角矩形边框及紧邻光晕; 范围: 图像中央偏左上区域, 约占画面 40%-90% 宽度和 5%-95% 高度; 由青蓝色渐变霓虹描边的圆角矩形轮廓(四角圆润, 左上-右下呈青绿到亮蓝的渐变)及其紧邻边框内外扩散的蓝色光晕组成, 背景为纯黑.
状态: `partial`.

草图目录:

- `S1` 单通道全屏 SDF 分层霓虹框: 12 个实现目标; 默认机制: M1 圆角矩形符号距离场; M3 SDF 带通白核遮罩; M5 黑底加色合成与软色调映射; 另 2 种, 详见 sketches.json.
- `S2` SDF 白模版 + 后处理泛光: 12 个实现目标; 默认机制: M1 圆角矩形符号距离场; M3 SDF 带通白核遮罩; M5 黑底加色合成与软色调映射; 另 2 种, 详见 sketches.json.
- `S3` 单 pass SDF 霓虹边框 + 双侧指数光晕 (默认方案): 10 个实现目标; 默认机制: M1 圆角矩形符号距离场; M3 SDF 带通白核遮罩; M13 fwidth 自适应抗锯齿; 另 3 种, 详见 sketches.json.

未完成工作 (共 12 项):

- 色相渐变的数学形式未定: 对角线性场 ([[M4]]) 与弧长周向场 ([[M6]]) 均可近似观测结果; 需更高分辨率取样区分, 特别是左边中点与底边中点的色相读数。
