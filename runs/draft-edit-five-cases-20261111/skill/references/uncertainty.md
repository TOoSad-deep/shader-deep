# 不确定性与必要缺口

已使用主流程的基本分类, 仍无法判断某项歧义是否影响必要观察或构成缺口时使用. 此处补充边界判断, 不要求每次填写问题列表都先读取.

## 先核对可见事实

回看原图中相关区域及全图位置, 区分“看得见”与“名称让人联想到”:

- 方位用画面坐标描述, 指明相对于哪个对象. 裁切需实际触及图边, 内部遮挡与画外截断分别描述.
- 轮廓只描述可见部分; 用可见端点、弯折与连接支持形态判断.
- 数量、颜色、尺寸采用图像支持的精度; 不靠猜测补齐精确数值.
- 静态姿态、明暗和叠加外观是观察; 运动、材质成因、隐藏形状或算法是解释, 不作为单图已证实事实.

修正能看清的错误后, 只对剩余的必要问题分类.

## 必要性仍不明确时

基础分类以主流程为准. 针对当前疑问依次判断:

1. 回到用户目标, 指出究竟需要覆盖哪一项可见外观或配合. 未要求的精确测量与实现猜测不扩大任务.
2. 尝试用图像支持的定性描述覆盖该目标. 能可靠表达时, 保留该描述即可.
3. 若不同读法会导致明显不同的结果, 写清可确认部分和待确认部分. 只在必要目标仍未覆盖时同时声明 gaps.

无法确定的局部不应使已经可靠观察的全图内容全部失效. 问题引用使用已有 E/F/R ID; 全图问题 refs 可留空. 用具体目标与原因说明范围, 无需附加泛化的准确性声明.

## 边界示例

- 未测一块色面的 RGB, 但色相和渐变方向清楚: 正常描述, 不填 gaps.
- 中央结构究竟相接还是分离会改变连接关系, 原图仍辨不清: 描述可见线段, 记录 open_questions; 若必要连接关系因此无法覆盖, 同时声明该 gaps.
- 用户明确要求每个标记的数量, 密集区无法数清: 这是必要缺口, 即使整体分布已描述.

判断明确后回到主流程, 将必要修正写入草稿. 可选列表只记录本次实际存在的问题与缺口.
