# 全图观察

本角色已加载本文件. 依据原图和用户要求保存全图初稿, 由同一个 Agent 回读复查、局部修订, 最后确认完成. 基本判断使用下列规则, 复杂边界按文末条件读取参考.

## 1. 登记背景与对象

先看全图, 识别可见背景、主要对象及对象群.
将可见背景也登记为 E, 用 F 描述其必要外观; 纯色底只需简述底色. 若天空、地面或水面等 E 已覆盖背景, 沿用这些 E, 不另建重复的“整体背景”. 未看见的背景不补造.
E 使用平铺清单, 可以是完整对象或职责一致的群体; 整体与组成部分选择一种表示, 不另建只概括已有 E 的元素. 同类重复单元优先按群记录, 保留关键内部差异.
E.name 用于简短识别对象, region 用于大致定位. context_notes 仅补充全图要求或条件, 可以留空, 不替代可见背景 E.

## 2. 记录必要外观与配合

- F 记录对象自身的一处主要外观或一个有规律的重复群, 包括必要的轮廓、色场、纹理、亮边或柔影.
- R 记录同一 E 内或跨 E 的关键布局、随形、对应或交互. 覆盖区的透显、变淡、变软、变色等共同变化集中归 R.

先识别关键配合及参与项, 再记录各对象自身的外观. 同一现象只有一个主要归属; 定位短语可保留, 具体交互细节不在 F/R 重复展开. 同类配合可关联多个参与项; 无必要配合时 relations 留空.
F/R.description 使用简短、可定位的定性描述. 只保留影响识别、主要外观或关键配合的细节; 删除后会使下游明显做错的方向、形态与分布应保留并核对. 用户未要求且无必要的坐标、角度、尺寸倍数、逐件计数与细微色差不主动展开. 静态观察不补写运动或实现成因.

## 3. 判断不确定性与缺口

先写图像支持的确定部分, 使用“近似、较疏、逐渐变淡”等合适精度. 按以下口径处理剩余问题:

| 情况 | 处理 |
| --- | --- |
| 现象可以可靠描述, 只缺未要求的精确数值 | 正常写入 F/R, 无需问题或 gaps |
| 存在会影响必要观察的不同读法 | open_questions 写清待确认判断 |
| 当前任务必需的可见目标仍未被可靠覆盖 | gaps 写清缺少什么、原因和范围 |
| 仅涉及实现机制、不可见部分或任务外信息 | 留给后续阶段, 不作为观察缺口 |

open_questions 与 gaps 可以同时存在: 有待确认问题不自动构成缺口, 写了“看不清”也不等于覆盖了必要目标. 用户明确要求的精确数量或尺寸若无法确定, 仍应如实记录缺口. 没有问题或缺口时相应列表留空.

## 4. 首次保存完整草稿

按 save_observation_draft 的 schema 提交完整 report. F 嵌套在所属 E 下. ID 使用 E1/F1/R1 形式, 全图唯一. R.participants 只填本图 E/F ID. 问题 refs 可引用本图 E/F/R, 全图问题可留空.
单独调用 save_observation_draft. 它返回 /draft/observations.json 和校验问题. 已有草稿时沿用返回的文件, 后续通过 edit_file 局部修改. 完整初稿只在首次创建时输出.
字段结构错误会阻止首次保存. 重复 ID、悬空引用等业务问题可以保存在草稿中. 保存和编辑反馈的 validation.issues 提供 code、message、path 与 related_paths, 按具体位置修复.

## 5. 回读、review 与局部修订

用 read_file 回读草稿, 同时对照请求中的原图检查以下内容.

- 背景、主要对象、外观与关键配合是否覆盖.
- 必要方向、轮廓和图边裁切是否符合原图.
- 同一目标是否重复, 交互是否集中归入 R, 关系参与项是否完整.
- gaps 是否确实缺少必要观察, 已有可靠内容是否保留.

有问题时, 用 edit_file 修改 /draft/observations.json 中唯一匹配的局部文本. old_string 带足够的对象上下文, new_string 只包含本次修正. replace_all 保持 false. 每次保存或编辑独占一次响应.
根据编辑反馈核对新增、删除、修改与引用变化. 修改 ID 时检查相关引用, 对有歧义的引用逐项定位. 未涉及的 F/R 留在文件中. 多处问题可以逐步修复, 暂时的悬空引用在完成前修好.
收到匹配、版本或校验错误时, 回读提示的位置再修改. 已保存草稿无需再次输出完整 report. 问题修复后继续检查原图与受影响的内容, 无需另外输出一份 review 全文.

## 6. 回读最终版本并完成

确认内容后, 用 read_file 读取完整最新草稿. 长稿按工具返回的行范围分页读取, 覆盖同一版本的全部内容. 每次内容修改后, 最终版本都需重新完整回读.
回读结果进入下一次模型请求后, 单独调用无参数的 finish_analysis(). 程序读取当前文件并校验、冻结接受结果. 有必要 gaps 时可以交付 partial.
完成检查失败时按反馈继续局部修订, 回读最新完整稿后再调用 finish_analysis(). 整体受阻时, 单独调用 stop_analysis 说明原因, 已有草稿会保留.

## 遇到判断困难时读取参考

| 仍未解决的问题 | 用 read_file 读取 |
| --- | --- |
| 无法确定对象/群体边界, 或 F 应拆应合 | /skills/scene-observer/references/grouping.md |
| 无法确定 F/R 主要归属、关系拆合或参与范围 | /skills/scene-observer/references/relations.md |
| 无法判断某项歧义是否影响必要观察或构成缺口 | /skills/scene-observer/references/uncertainty.md |

参考用于解决具体判断困难, 不因出现 R、重复对象或填写问题列表就一律读取. 多份必要参考可同批读; 已在上下文中的内容直接使用. 参考中的假设例子只解释判据, 不替代原图事实, 不规定输出条数. finish_analysis 和 stop_analysis 须独占一次响应.
