## 方案

- S1 对角线三发光体霓虹图
  - 完整性为 completed
  - 单一 GLSL ES 3.00 Pass, 入口 mainImage(out vec4, in vec2), 使用 iResolution/iTime (iTime 可不参与静态外观, 仅保留 uniform 接口)。执行顺序: (1) M1 建立纵横比校正坐标 uv (y 向上); (2) 用 M2/M3/M4 分别求三个发光体相对各自中心的 SDF: 五角星中心约 (0.18, 0.36), 外接半径约 0.13, 旋转约 -8° (姿态略倾斜, 允许 ±5° 内微调), 圆角约 0.02; 圆心约 (0.00, 0.00), 半径约 0.10; 心形中心约 (-0.19, -0.35), 半高约 0.12, 旋转 180° 姿态内置; 位置均按 1280x720 观察标定 (uv = (fragCoord-0.5*res)/res.y, y 向上), 三个中心近似共线且间距相等 (约 0.40 uv 单位), 满足 R1 的右上—左下均匀对角线排列; (3) M5 对每个 SDF 生成宽域同色晕: 星暖黄橙 (约 vec3(1.0,0.62,0.25)), 圆粉紫红 (约 vec3(0.85,0.35,0.75)), 心蓝 (约 vec3(0.35,0.65,1.0)); 心形晕对 d 施加向下方/左下的轻微方向偏置使扩散偏下 (F8); 三层加法累加, 交叠区自然形成暖黄→紫粉→蓝的柔和过渡 (R3), 远离处衰减回纯黑 (F2); (4) M6 生成三个实心体: 星中心亮黄近白 (约 vec3(1.0,0.97,0.75)) 边缘饱和黄 (约 vec3(1.0,0.85,0.3)); 圆中心近白 (约 vec3(1.0,0.95,0.98)) 边缘淡粉; 心中心浅蓝近白 (约 vec3(0.8,0.95,1.0)) 边缘亮蓝 (约 vec3(0.5,0.8,1.0)); (5) M7 将实心体色场加到光晕背景之上, 输出最终颜色。无外部纹理, 无多 Pass。
