# 全图机制与方案报告

## 规划要求

依据固定整图观察与原图提出可在当前单 Pass 环境实现的完整方案, 保留主要外观及关键关系, 给生成 Agent 清晰可执行的安排.

## 方案

- S1 单 Pass 全屏：环纹背景场 + 8 字 SDF 图形
  - 完整性为 completed
  - 整体为单 Pass 全屏 shader（GLSL ES 3.00, mainImage），以像素坐标 p（居中、按高度归一）统一驱动。执行顺序：1) 坐标系：p = (fragCoord - 0.5*iResolution)/iResolution.y，画面中心为原点，横幅 1280x720。2) 共享场：调用 [[M1]] 一次求得 d1、d2、dOut=min(d1,d2) 与 dSlot。图形中心置于画面中心，整体高度约占屏高的 0.85（生成阶段精调），保证 R1 的居中关系。上/下两枚六边形 180° 旋转对称并沿 x 错位，两条零等值线在腰部相互穿越（F5）；S 带为圆头胶囊链：上瓣内竖直短段—腰部斜段—下瓣内竖直短段，斜段走向按原图 S 形对齐。3) 背景层（F1/F2/R1）：调用 [[M4]]：直接对共享的 dOut（原始 min 并集场）取 g = dOut(p)，对 g/freq 取 fract 得橙/深棕交替细密环纹（环距约屏高 1/45 量级，生成阶段拟合）。min 折痕沿 y=0 向左右延伸为水平接缝与成对对称折点（F2），近图形随形弯绕（R1）。4) 暗晕（R2）：用 [[M5]] 以 g 的窄带把背景环纹向深棕压暗、贴边最深向外恢复。5) 图形层（F3/F4/F5/R3）：以 [[M2]] 在 |d1|≈0 与 |d2|≈0 各取一条白描边（两线在腰部相互穿越形成 S/X 自交，F5），并在 S 带边界（sSlot≈0）取白亮窄边；带内部（sSlot<0）填深藏青；其余内部区域（dOut<0）用 [[M3]] 的 fi = min(|d1|,|d2|,sSlot) 条纹场生成亮蓝/深蓝交替嵌套环纹，环纹随两枚轮廓向内收缩并沿腰部交叉同步折弯收拢（R3），上/下瓣内的圆头细长窄内圈即 S 带两端圆头外的等值线（F4）。浮雕明暗用 fi 梯度着色（受光方向按原图左上→右下）。6) 合成：最终色 = 暗晕后的背景色，图形区域（dOut<0）叠加带芯暗色与嵌套条纹，白描边最上层。图形区域由 dOut 符号自然裁切背景；整图除背景环纹与中央 8 字外无其他元素（context_notes）。
- S2 完整备选：逐层缩小的嵌套条纹
  - 完整性为 partial
  - 与 S1 默认整体组织相同：M1 求得共享 d1/d2/dSlot，M4 生成背景环纹（含 y=0 接缝与随形弯折），M5 施加图形四周暗晕；图形侧先 M2 白描边，再 M3 嵌套条纹。唯一区别：M3 的条纹不以 fi 相位直接取 fract，而以整数层计数配合逐层缩小的六边形与 S 带轮廓重建，保证腰部交叉处每圈条纹几何一致。合成顺序与裁切同 S1 默认第 6 步。
