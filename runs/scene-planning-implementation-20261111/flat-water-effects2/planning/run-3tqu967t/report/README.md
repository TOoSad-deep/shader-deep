## 方案

- S1 红色日落海景单 Pass 程序化合成
  - 完整性为 completed
  - 共享构图常量（全方案统一）：画布 1280x720；地平线高度 horY≈0.48H（可 0.46–0.50H 微调）；太阳中心 SC≈(0.50W, 0.21H)，日轮半径≈0.15H；日轮核心亮度为全图最亮锚（≈1.0）。单 Pass、无外部纹理，全部程序化求值；iTime 不参与动画（time=0，静态单帧）。合成顺序：① [[M1]] 渲染天空底色：以 SC 为焦点，地平线以上由近阳亮暖粉向四周与远处暗红衰减，叠加轻微垂直梯度，无云无纹理（F1）。② [[M2]] 在天空底色上先加红色大光晕、再叠日轮：日轮核心纯白、边缘窄环暖粉软边、轮廓清晰（F3、F4）；光晕色板同时作为海面基调与雾色的共同来源（R1）。③ [[M3]] 对 horY 以下像素求水区域遮罩、深度 t 与水纹采样坐标：近地平线（t 大）高频率小幅度，近底部（t 小）低频率大幅度。④ [[M4]] 在水纹坐标上求 2–3 层值噪声波纹高度场及屏幕空间坡度。⑤ [[M5]] 以暗红褐水底色为基，用高度场做峰谷明暗调制：波峰微亮偏暖、波谷变暗，画面底缘再叠加随 y 增大的压暗使波谷暗部最深；近景衰减高频层并增大软化以模拟大而模糊的波纹（F5）。⑥ [[M7]] 在水体着色之上叠加太阳反光带：水平以 SC.x 对齐、纵向三段——近地平线段收窄并由高频噪声阈值化成密集细碎光点且趋模糊（F9），中段最亮（F7），近底部段随坡度散成数条弯曲亮弧、为水面最亮高光（F8）；整体亮度锚定日轮亮度（R2），碎斑与弧线由 [[M4]] 的高度/坡度驱动（R3）。⑦ [[M6]] 在地平线水侧叠加微亮、模糊的水天线（F6）。⑧ [[M8]] 最后跨地平线做雾状混合：horY 两侧有限高度内把水体着色与天空底色向共享亮暖粉雾色衰减混合，柔化天海过渡（F2）并统一全图暖红基调（R1）。混合与裁切规则：光晕以加色方式允许少量越线照亮地平线附近海面，日轮严格裁切于天空区域、不进入水区；反光带仅作用于水区域遮罩内；⑧ 位于 ⑥⑦ 之后作为最终统一过渡层；结尾做软色调钳制，保持最亮次序为日轮 > 近景反光弧 > 中段反光带 > 水天线。数值拟合（各色值、半径、衰减曲线、阈值）由生成阶段承担。
