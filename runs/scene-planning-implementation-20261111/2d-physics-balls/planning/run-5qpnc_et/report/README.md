## 方案

- S1 单 Pass 分层平涂: 底色-卡片投影-卡片-齿轮群表
  - 完整性为 completed
  - 坐标约定: p 用图像像素坐标、y 向下 (p=vec2(fragCoord.x, iResolution.y−fragCoord.y)), 下表数值按 1280×720 直接可用; 单 Pass、无纹理采样, iTime 不参与 (静帧)。合成顺序: [[M1]] 底色 → [[M2]] 投影环 → [[M2]] 卡片白底 → 按 [[M4]] 表序逐枚绘制 [[M3]] 齿轮, 后绘覆盖先绘; 所有 SDF 边缘用 ≈1–1.5px (按 fwidth 比例) 的 smoothstep 抗锯齿; 全图纯色平涂, 无描边、无渐变、无纹理。【F1–F3 背景与卡片】背景平涂 ≈#F2F2F3, 卡片圆角使四角自然露出较宽底色; 卡片矩形 x∈[178,1104]、y∈[50,670]、圆角半径≈56, 平涂纯白; 投影: 沿卡片 SDF 向外 0→≈22px smoothstep 衰减的各向同性柔和环, 峰值把底色向 ≈#E4E5E7 压暗约 4–6%, 无方向偏移。【F4 齿轮单元】全群等径, 外径≈110 (R≈55): 根圆 R0≈38、齿高 H≈17、齿数 8、相位全群一致取 0、中心孔半径≈15; 平顶齿参数 (以周期 1/8 为单位): 上升 0.02→0.045、平顶 0.045→0.075、下降 0.075→0.10 (齿基宽≈29°、谷宽≈16°), 允许生成阶段微调。【F5 配色】绿≈#3EA54B、黄≈#FCC010、红≈#E9445A、蓝≈#4A8AF5, 可按固定观察取样微调, 保持饱和纯色; 全群 20 枚、四色各 5 枚。【F6/R1/R2 布局表】三行 y≈401/501/598, 相邻行水平错位约半列; 20 枚中心与颜色 (px): 左簇 顶行 (258,401,绿) (371,400,黄) (507,425,绿) (614,428,黄); 中行 (316,500,黄) (418,501,红) (560,522,黄); 底行 (256,597,黄) (366,598,绿) (481,599,绿)。右簇 顶行 (862,401,绿) (962,404,蓝); 中行 (703,504,蓝) (803,501,红) (906,501,蓝) (1012,502,蓝); 底行 (645,598,红) (751,597,红) (862,597,红) (963,598,蓝)。绘制序 = 上表顺序 (自上而下、行内自左而右): 下行/右列齿轮在前, 每处交叠一方轮廓完整、另一方被局部遮挡 (R1); 若个别前后关系与原图不符, 仅交换表中相邻两项。【咬合与中缝校验 (关键关系)】簇内相邻 (同行与对角) 中心距目标 100–116 (齿缘叠压或恰触), 保留观察到的两处簇内松位 ≈135–145 (顶行第 2–3 枚之间、中行红–黄之间); 跨簇禁止叠压; 最窄细缝位于右簇左下红 (645,598) 与左簇黄 (560,522) 之间, 目标中心距 ≈113–116, 即细缝 3–6px、贯通不闭合 (开放问题的处理: 保留小正缝隙, 与当前观察『贯通细缝、近乎接触』一致; 若更高分辨率证实完全贴合, 把该对距离压到 ≈110 相触即可); 其上一处颈部 (614,428黄↔703,504蓝) 取 ≈115–118 (细缝 5–8px, 若原图该处更宽可放宽至 15–25px 缝); 缝体自细缝向上加宽: 中行 ≈34px → 顶行 ≈138px; 细缝下方的小袋 (481,599绿↔645,598红 ≈54px) 属缝体下端, 连通底边留白。初值有偏差时, 在 ±10px 内平移相关齿轮的 x (行 y 不动) 校准上述距离, 优先移动中缝两侧齿轮。【R2 与卡片】底行齿轮下缘距卡片下缘≈16px, 左簇左缘距卡片左缘≈25px, 右簇右缘距卡片右缘≈37px, 带顶 (y≈346) 以上为大片留白, 齿轮带整体位于卡片下半部; 20 枚齿轮以常量表+循环求值, 性能充裕。
