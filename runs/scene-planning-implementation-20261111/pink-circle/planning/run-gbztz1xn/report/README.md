## 方案

- S1 白底粉红光面球 · 单 Pass 解析合成
  - 完整性为 completed
  - 几何底座：[[M1]] 一次求值并以全图共享——以 iResolution 短边(≈505px)归一 fragCoord，画布中心为原点、y 向上；球心 c≈(-0.005,0.025)、半径 R≈0.426，输出 d、v、r、θ 供所有层使用。iTime 不使用(静态图)，全程解析求值、无纹理、无循环，满足单 Pass 约束。(1) 背景层 bg：[[M3]] 纯白底叠加右下柔影(偏移圆盘心 c+R·(0.08,-0.15)，衰减长度≈0.22R，峰值不透明度≈0.35，色≈#ECE1E6)；随后加 [[M7]] 实例A：左下外侧窄淡粉亮边(r∈[1.00,1.06]、θ0≈-135°、半宽≈45°、add≈#FBDDE6)。球外带必须挂在背景层，mask 混合后会被清零。(2) 球面底层色场：[[M4]] 取 L2D=normalize(vec2(-0.28,0.92))，t=0.5+0.5·dot(unit(v),L2D)，用偏置/旋转微调使 depth 峰位于高光中心右下(R2)，可乘 (1-0.3r²)；[[M5]] 以 depth 走 pale≈#FDF2F4/mid≈#F8C6D3/deep≈#E92B5D 两级 smoothstep(节点≈0.05/0.55/0.95)，保证底部中央趋白、顶部偏左最浓。(3) 球面层轮缘带 [[M7]] 四实例，先乘暗后加亮：① 左上深色细边 r∈[0.90,1.00]、θ0≈120°、半宽≈55°、mul 深玫红(暗化至≈0.72 且色相偏玫红)；② 右下弯月反光(F6) r∈[0.62,0.96]、θ0≈-55°、半宽≈75°、add≈#FFE9F0、宽而柔；③ 右下轮缘亮边 r∈[0.92,1.00]、θ0≈-50°、半宽≈60°、add 近白；④ 右上内侧细高光条(F8) r∈[0.90,0.99]、θ0≈40°、半宽≈35°、add 微量白。(4) 高光：[[M6]] 中心 v_h≈(-0.33,0.52)，主斑沿切向(≈32°)拉长 σ≈(0.28,0.11)、宽晕 σ≈(0.50,0.30) 低强度，加于最上层并 clamp 至纯白，保持全图最亮。(5) 合成输出：[[M2]] mask=smoothstep(aa,-aa,d)、aa≈2px/短边；out=mix(bg,球面层,mask)。角度约定：y 向上，左上≈135°、右上≈45°、右下≈-45°、左下≈-135°。全部数值为初值，生成阶段可纯数值调优。关键关系落点：R1 由(1)柔影方位与衰减承担；R2 由(2)(4)共用左上光向、深峰偏置承担；R3 由(3)的①与②③明暗对置承担。
