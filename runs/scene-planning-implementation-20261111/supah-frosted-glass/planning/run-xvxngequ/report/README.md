## 方案

- S1 灰底上锐边渐变圆与柔焦罩层的分层程序化合成
  - 完整性为 completed
  - 单 Pass 全屏程序化合成: mainImage 以 gl_FragCoord.xy 取像素坐标 p (y 向上, 画幅 1280×720), 不使用纹理与 iTime (t=0 静态), 全部柔焦用解析衰减场实现.

几何定位 (落实 R1, y 向上像素坐标): E2 圆心 c2=(566,332)、半径 r2=146; E3 圆心 c3=(712,390)、半径 r3=145. E3 位于 E2 右上方 (圆心偏移约 +146,+58), 半径相近, 圆心距约 157, 形成画面中央偏右上的透镜形重叠区; 两盘连同羽化均完整落在画框内, 无需裁切.

求值顺序 (先算场, 后合成):
1) [[M3]] 场: d3 = length(p-c3)-r3; e3Mask = 1 - smoothstep(-0.10*r3, 0.35*r3, d3), 即内部 plateau、外缘约 50px 羽化的柔焦覆盖场 (F4, 顶部与右侧同样羽化); 合成参数: 峰值不透明度 a3≈0.6, 填充色 vec3(0.930,0.930,0.940) (F5, 右半均匀、仅比底色略亮).
2) [[M5]] 场: cover = smoothstep(0.35, 0.85, e3Mask); w2 = mix(1.5px, 30px, cover). E2 的左缘与下缘远离 E3, 该处 e3Mask≈0, 锐度自动保留; 下限 0.35 是因为 E3 羽化外带会轻触 E2 顶部边缘, 需保证该处仍基本锐利.
3) [[M2]] 场 (F2/F3): d2 = length(p-c2)-r2; alpha2 = 1 - smoothstep(-w2, w2, d2); 表面色沿轴 g = normalize(vec2(0.82,-0.50)) 取 t = clamp(0.5 + dot(p-c2, g)/(2*r2)), 色带 青 vec3(0.10,0.61,0.62) → 中 vec3(0.06,0.45,0.66) → 深 vec3(0.03,0.36,0.70), 使左缘青绿最鲜明、右侧与下部蓝色最深.
4) [[M4]] 场 (F6): e = (p-b0)/s, 团块中心 b0=(655,372), 半轴 s=(105,105); blobA = 0.85*exp(-dot(e,e)); 紫色 vec3(0.56,0.34,0.72). 浓度峰紧贴 E2/E3 重叠区, 向右渐淡、向左下渐隐.

合成顺序 (back-to-front, 落实 R2): col = vec3(0.915,0.915,0.924) ([[M1]]); col = mix(col, E2表面色, alpha2); col = mix(col, E3填充色, a3*e3Mask); col = mix(col, 紫色, blobA); 输出 vec4(col, 1.0). e3Mask 须先于 E2 的 alpha2 求值 (供 [[M5]] 使用), 其后按上述顺序混合; 各场与颜色均为逐像素纯函数, 无状态、无共享纹理.

关键关系核对: 两圆交点约为 (595,475) 与 (685,247) (y 向上), 其间经最右点 (712,332) 的 E2 右上弧段被 E3 覆盖——该弧段因 w2 放大而隐没, 蓝与紫叠成靛蓝偏紫并随 blobA 向右衰减为灰紫; E2 下缘 cover≈0, 保持约 1.5px 锐边 (R2 的未覆盖部分). 所列不透明度、羽化宽度、色带端点与团块半径均为起点值, 属生成期数值调优, 以原图为准微调; 若出现可见色带可叠加极小幅度的抖动.
