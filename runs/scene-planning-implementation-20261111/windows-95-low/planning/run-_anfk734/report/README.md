## 方案

- S1 波浪旗帜+像素消散单 Pass 方案
  - 完整性为 partial
  - mainImage 中: 1) 以 M1 输出青绿底色; 2) 以图心约 (770,370) 像素、旋转约17°、缩放使旗帜占约 310×440 px 建立 M2 的波浪旗帜坐标, 波浪使上下缘起伏、左端略收窄上扬, 得到旗帜外缘粗黑描边 mask; 3) 在 u∈[u_solid,1] 区间用 M3 实心渲染: 红面与蓝面靠近十字的内侧部分、右上浅绿、右下金黄、黑色十字带与外缘粗黑描边; u<u_solid 的红/蓝象限及其黑色边框带交给 M4; 两区共用同一颜色函数, 使黑框、黑十字与色面在交界处连续 (R2); 4) 用 M4 把 u<u_solid 的区域及其向左上延伸的散列带按与旗帜波浪坐标对齐的方块网格量化: 行为沿波浪弯曲的等 v 行 (F7), 自上而下依次为黑色描边行、红色面行、十字黑带行、蓝色面行、黑色描边行 (R1/R2); 靠近 u_solid 处方块大而近满格, 沿 -u 方向尺寸与保留率(hash(格索引) 阈值, 确定性, iTime=0)递减, 间隙变大, 远端只余零星小点 (F6), 保留率归零处以背景露出; 旗帜左缘的黑色锯齿收碎由边框行的方块自然形成 (F4); 5) M5 按背景→方块→旗帜顺序合成, 图形四周保持干净背景, 无投影 (R3)。全部数值(中心、角度、尺度、网格、色值)由生成阶段拟合。
