依据固定整图观察与原图提出可在当前单 Pass 环境实现的完整方案, 保留主要外观及关键关系, 给生成 Agent 清晰可执行的安排.

## 方案

- S1 单 Pass 网格台面双水渍 (左上光)
  - 完整性为 completed
  - 目标: 1280x720 单 Pass GLSL ES 3.00, 入口 mainImage(out vec4, in vec2), 仅用 iResolution/iTime, 无外部纹理; 场景静态, iTime 不参与。以下长度均以图高为单位。
1. 坐标与全图共用光方向: 按 [[M1]] 建立 p 与 aa=1.5/iResolution.y; 全图唯一光方向 L=normalize(vec2(-0.6,0.8)) (指向左上), 底色渐变亮轴取其反向 ([[M1]] 的 D≈normalize(vec2(0.8,-0.6))), 背景明暗与水滴受光方向同源, 落实 [[R2]]。
2. 背景纯函数 bg(p), 落实 [[F1]] [[F2]]: bg(p)=base(p)*网格因子, 由 [[M1]] (亮端 vec3(0.81,0.83,0.85) 在左上, 暗端 vec3(0.37,0.42,0.47) 在右下) 与 [[M2]] 合成; 网格起始值: cell=0.25 (约 180px 方格), phase≈vec2(-0.006,0.0), 即竖线位于 x≈-0.756,-0.506,-0.256,-0.006,0.244,... (px 约 96,276,456,636,816,996,1176), 横线位于 y=0,±0.25,±0.5 (px 0,180,360,540,720), 格线延伸至图边被裁切; 线半宽 w≈0.0014 (约 2px), lineDark≈0.78。bg(p) 必须是仅依赖坐标的纯函数, 主采样与第 4c 步水下重采样共用同一函数 (关键共享结果)。
3. 形体与布局, 落实 [[F3]] [[F6]] [[R3]]: 用 [[M3]]。大滴: 左圆 cL≈(0.008,0.008) rL≈0.158; 右圆 cR≈(0.305,0.007) rR≈0.095; smin k≈0.25-0.3 起步 (两圆间隙≈0.045, k 需足够融合且不过度外鼓); 校验点: 腰部顶缘在 x≈0.19 处高度≈+0.13 (px 约 266), 左端达 x≈-0.15 (px 约 532), 右端约 x≈0.40 (px 约 928), 右头上/下缘 px 约 287/423, 轮廓光滑闭合、左宽右窄、无腰部凹陷。小滴: 圆 cS≈(-0.45,-0.24) rS≈0.12 (包围盒 px 约 [230,402]x[450,620], 约占一格)。布局落实 [[R3]]: 大滴横跨约 2.2 格, 小滴位于大滴左下方, 两滴轮廓最近间隔大于 0.1 图高、互不接触; 全图仅此两处水渍, 台面无其他物件。
4. 渲染顺序 (单次遍历, 按序混合):
  a. col=bg(p)。
  b. 接触柔影 ([[F4]] [[F7]] 的下缘柔影分量, [[M5]] 方法 c): 先在背景上对两滴施加外侧下缘柔影 (w2≈0.03, 强度≈0.2, 方向权重 shDir≈normalize(vec2(0.35,-1.0)) 向下稍偏右, 与 [[R2]] 的左上光相对), 只作用于 d>0 区域, 不得进入内部掩码。
  c. 水体内部 ([[F5]] [[F8]] [[R1]], [[M4]]): 各滴 m=smoothstep(aa,-aa,d); 采样坐标 p'=mix(p, 滴心, bend*m), 大滴 bend≈0.06 (形心≈(0.12,0.007)), 小滴 bend≈0.09 (心=cS); 内部色=mix(bg(p'), 亮度灰(bg(p')), 0.06)*0.90; col=mix(col, 内部色, m)。结果: 水下格线透出、整体轻微加深、并轻微错位/近缘弯折, 呈现 [[R1]] 的透明覆盖关系。
  d. 边缘光影 ([[F4]] [[F7]] 的缘上分量, [[M5]] 方法 a,b): 上左内缘细亮高光 (w1≈0.004, 白色加法, 权重 max(dot(n,L),0)); 下右内缘弱暗化 (带宽≈0.01, 系数≈0.12, 权重 max(-dot(n,L),0)); 在内部覆盖之后绘制, 只影响滴缘。
  e. 输出 vec4(col,1)。
5. 一致性与抗锯齿: 法线用中心差分 (步长≈aa); 所有掩码与带宽以 aa 平滑; 上述数值均为起始值, 允许生成阶段微调轮廓、位移与强度, 但必须保持: 水下格线可见且仅轻微错位 ([[R1]]), 全图单一左上光方向 ([[R2]]), 两滴不接触且仅此两处水渍 ([[R3]]), 除格面与两处水渍外无其他元素。
