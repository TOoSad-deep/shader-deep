## 方案

- S1 噪声极光幕场+镜像倒影夜景
  - 完整性为 partial
  - 整体组织 (自底向上合成, 顺序即 mainImage 内求值顺序): 1) 用 M1 建 uv, 取地平线 y≈0.38. 2) 水面分支: 基色取 M8 (内含 R4 深蓝黑底与波纹), 再用 M7 以镜像 uv 计算极光倒影并与 M8 基色相加 (R1), 倒影整体乘约 0.35-0.5 衰减; 随后 M9 叠加稀疏白色反光 (R2), 并用 M6 返回的剪影上缘在剪影正下方压暗一层 (R5). 3) 天空分支: M2 提供底色; M3 以两组不同 seed 的噪声幕场给出绿/蓝紫极光强度, 与 M2 结果相加; M4 叠加光柱表: 右侧 2-3 簇亮绿光幕带核心 (F4), 顶中斜向亮带 (F5, 由 M3 高亮脊线近似), 左缘小竖柱与淡蓝紫细柱 (F6), 中部偏右近地平线数根高低不一的短柱 (F7, 下端止于剪影上缘, 即 R3 的收束), 顶缘宽晕 (F14) 与右缘/右下柔斑 (F15) 由 M3 低频大尺度权重补足; 各柱边缘淡蓝紫混色与向夜空淡出按 F8 在 M3/M4 的色混合中体现. 4) M5 在天空加两层星点 (F2/F3). 5) M6 最后在地平线附近覆盖近黑剪影并叠加其上的幕状暗影 (F9/F13), 实现对亮斑的黑色遮挡 (R3). 混合规则: 底色为基准, 极光、星点均加性叠加并 clamp, 剪影为覆盖性遮挡, 水面域与天空域按 y 与剪影上缘分段切换. 关键关系核对: R1 由 M7+M8 完成, R2 由 M9 完成, R3 由 M4 下端约束 + M6 遮罩完成, R4 由 M8 完成, R5 由 M8 的压暗罩完成. 全部在单 Pass 内以纯函数求值, 无外部纹理.
