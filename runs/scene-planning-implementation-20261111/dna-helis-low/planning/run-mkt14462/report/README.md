## 方案

- S1 双螺旋阶梯波浪单通实现
  - 完整性为 completed
  - 整体流程 (单 Pass, GLSL ES 3.00, mainImage(out vec4, in vec2), 仅用 iResolution/iTime, iTime 不参与静态外观): (1) M1 将 fragCoord 归一化, 输出对角参数 s 与法向偏移, 基线自左下角内延伸到右上角外, 保证左下与右上两端结构被图边裁切 (F2)。背景先填纯黑实现 F1。(2) M2 以 s 为自变量给出两条正弦波浪链的中心轨迹, 相位差约 π, 波幅与波数经参数选择使左中部与右上部各出现一个波峰、中部回落 (R2); 细线群与球群共用此轨迹故随波浪一同起伏 (R2)。(3) M6 在三个交叉区间 (左端附近、画面中部、右端图边处, 后者延伸出画布) 将两链中心按 smoothstep 包络向对方收缩, 输出替代后的有效链中心; 收缩使交叉处连线自然变短、两链球体贴近, 右端被图边裁切 (R3, F6 的交叉变短部分)。(4) M3 以固定 spacing 沿 s 离散出梯级索引 i 与每级两端点 (分别取在收缩后的 chainA/chainB 上), 得到近似平行的梯级单元沿整条结构重复 (R1); 同一 i 上连线长度本身沿波浪起伏变化, 加上 M6 的交叉收缩, 共同形成 F6 的长短节奏。(5) M5 对每个像素求到最近梯级线段的距离, 生成均匀粗细细线的浅灰遮罩 (F5)。(6) M4 由 i 经确定性哈希派生两端球各自的灰度分档 (白/浅灰/中灰/深灰/近黑)、半径缩放与微小抖动, 两端不同 salt 导致一亮一暗、大小相异 (R1, F3, F4); 半径与明暗不与 s 相关, 保证全链深浅混杂。(7) M7 对每颗球以抗锯齿实心圆绘制, 颜色取 M4 灰度, 叠加在 M5 线条之上 (端点处线被球盖住, 线两端各接一颗球, R1)。(8) 最终颜色 = 黑底 + 线遮罩*浅灰 + 球遮罩*球灰度。数值调优项: spacing(约整图 12-16 级)、A/k/相位、交叉区间中心与半宽、线宽(1-2px)、半径均值、灰度分档表——留待生成阶段拟合。
