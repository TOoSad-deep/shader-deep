- E2 消散像素方格群; 范围: 画面中左上方, 紧邻旗帜左侧 (约 x 350–710, y 95–465)
  - F4 多行小方格沿与旗面相同的波浪弧线排列, 自旗边向左上方逐行展开, 整体呈向左上飘散的带状分布
