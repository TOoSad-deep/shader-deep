# 局部与整图渲染评审指标

- 状态: 首版准则已用于评审角色与领域合同. 工程验证见[实施记录](work-items/independent-visual-review-implementation-20261117.md#10-2026-11-18-工程实施记录), 真实模型质量校准待开展.
- 适用范围: 比较固定参考与实际渲染图. `local` 必须声明 `target_kind=feature|element`; `scene` 不填写局部类型. 程序选择对应层级模板.
- 架构、输入捕获与执行终态见[独立视觉评审设计](work-items/independent-visual-review-design-20261117.md).

## 1. 指标的使用方式

首版统一六个维度的分类、状态含义、证据结构与结论派生, 按特征、元素、整图模板具体化检查重点. 每次任务在评价候选前固定 `BoundReviewCriteria`, 其中声明六维的必查内容、范围外内容和已有容差. 同一报告格式不表示三个层级具有相同检查清单.

评审输出六维状态与可见证据, 不转换为加权总分. 只评价当前绑定范围内的视觉结果, 原因诊断、假设成立性和代码修改不在此准则中.

评审按以下顺序完成:

1. 读取固定模板与本轮绑定, 确认目标、范围和可比较的材料. 完成条件是能说明“评什么、哪些内容在范围外、哪些必要信息缺失”.
2. 按绑定执行六维检查. 材料不足记录未评项, 不依据候选表现删减必查内容. 发现需要改变标准的冲突时停止并说明, 由调用方建立新绑定.
3. 先看整体目标, 再检查各项差异. 每项都应有状态与可核对的说明, 差异对应问题条目.
4. 对问题说明其对本次目标的影响, 据此分为 `minor` 或 `major`.
5. 按第 5 节汇总结论, 同时保留未评部分. 完成条件是范围、六项状态、问题、限制与结论互不矛盾.

用户明确要求优先于模板默认值, 参考图提供可见依据. 绑定应保留本次适用的明确要求, 不能因扩大到整图而自动放宽. 已明确允许的变化不记为差异. 当前范围内存在证据歧义时登记未评项; 若必须改动绑定才能消解目标冲突, 不在原任务里选择有利于候选的解释.

### 1.1 三种层级模板

| 模板 | 默认评审重点 | 本轮绑定需要具体化的内容 |
| --- | --- | --- |
| `feature` | 一项指定可见表现是否得到重建 | 是轮廓、亮带、渐变、纹理还是透显; 必查属性和必要邻域 |
| `element` | 一个完整对象的必要特征与内部配合 | 必要组成、内部比例、形状、色场、表面和内部关系; 哪些外部关系在本轮范围内 |
| `scene` | 整体构图与对象组合后的表现 | 必要内容、布局、整体明暗/色调、跨元素关系及仍须满足的明确局部要求 |

模板共用 `major/minor` 语义, 只改变具体检查重点和锚点. 同为 `feature`, 渐变需要核对颜色分布与过渡, 轮廓需要核对形状与软硬边; 这些都在共同六维中绑定, 不创建新的报告类型或独立 Agent.

“默认重点”不是固定权重. 元素的内部完整性和整图的组合关系必须直接观察, 不通过平均下层评审结果得到. 已存在的局部报告可供调用方追踪, 不替代本轮固定图像的独立评审.

### 1.2 一次绑定的示例

`local + feature`, 目标为“只检查前圆亮带的宽度和软边”:

- `content.required_checks`: 目标亮带是否存在.
- `shape.required_checks`: 宽度分布、软边衰减是否符合参考; `shape.excluded_checks`: 不在本轮检查的支撑轮廓曲率.
- 其他维度未纳入本轮时, 明确写出排除内容与理由. 若目标还要求沿轮廓随形, 则应在看候选前将相应关系纳入绑定.
- 没有来源明确的容差时不发明像素或百分比阈值. 目标亮带缺失属于可见问题, 不能把 `content` 改成不适用.

首版具体验收说明来自调用方和既有目标材料, 程序只负责模板选择、合成、结构校验与冻结. “动态绑定”不是让评审模型在看到候选后临时发明标准. 后续若需要模型辅助生成检查内容, 应另行设计只看参考的准备步骤, 不混入本版执行链.

## 2. 六个视觉指标

指标 ID 在报告中固定, 每项恰好记录一次. 每项只需状态、简短依据和问题引用; 不按每个 E/F/R 再复制完整表格. 下表给出分类含义, 实际检查内容以本轮绑定为准.

| ID 与指标 | 具体观察内容 | 局部 `local` | 整图 `scene` |
| --- | --- | --- | --- |
| `content` 目标完整性 | 目标是否存在, 必要部分是否缺失、多出或数量错误 | 指定特征/元素内部的必要内容 | 整图主要对象、背景结构和关键效果 |
| `layout` 位置与比例 | 位置、大小、朝向、间距和画面裁切 | 仅在目标包含且坐标可比较时检查 | 检查整体构图与各对象相对安排 |
| `shape` 形状与边界 | 轮廓、曲率、开口、厚度、连接及边缘软硬 | 指定目标的可见几何表现 | 主要对象的形状及轮廓一致性 |
| `color` 色彩与明暗 | 主色、亮暗位置、渐变方向、对比和色场分布 | 指定目标的颜色和明暗表现 | 整体色调与主要区域之间的明暗层次 |
| `surface` 纹理与表面细节 | 平滑度、纹理尺度/方向/密度、条带、噪点及局部发光分布 | 指定目标的表面表现 | 各区域细节与整图视觉表现 |
| `relations` 可见关系 | 遮挡顺序、透显、对齐、随形、接触区变化和相互衔接 | 只评价声明范围内且有对应上下文的关系 | 检查主要跨元素及元素内部关系 |

### 2.1 适用范围的规则

- 局部类型与模板已经固定. “只评亮带的宽度和软边”不会自动变成检查整个元素的色彩与布局; “评整个圆形元素”的绑定应覆盖其必要可见外观.
- `scene` 模板通常先检查内容和布局. 纯背景没有对象关系时, 在绑定中记录排除依据; 不能因为候选只剩背景而排除参考中必需的对象或关系.
- 平滑表面也是 `surface` 可以检查的表现. 完整元素或整图任务中, 不能仅因参考没有纹理而排除它; 已纳入平滑度检查时, 候选新增噪点仍应报告. 明确只评其他特征时才可在绑定中将其列为范围外.
- 相同画布的局部比较保留对应坐标. 移动候选裁剪框去追随物体会掩盖错位, 不能据此证明位置正确.
- 缺少坐标映射时, 仍可评价可比的内部形状; 绝对位置和尺度不能猜测. 缺少背景时, 已明确要求的透显或融合属于无法判断, 不属于不适用.
- 单帧只判断该时间点. 时间变化正确性需要另行提供对应帧, 不从静态结果推断.

### 2.2 问题的主要归属

每个问题选择一个主要指标, 可被其他相关指标引用, 但不重复生成问题条目. 用“看到什么差异”确定主要归属, 不猜测内部原因.

例如主体整体偏右主要属于 `layout`; 同一形状移动后造成的接触间隙可由 `relations` 引用该问题. 若还存在独立的前后遮挡颠倒, 则另记一项关系问题. 必要圆环内孔消失主要属于 `shape`; 整个圆环不见主要属于 `content`.

## 3. 每项指标怎样分级

| 状态 | 含义 | 必须给出的依据 |
| --- | --- | --- |
| `match` | 本项有绑定的必查内容且可判断, 没有发现超出当前要求的可见偏差 | 说明已核对的对象或表现; 不等于像素完全相同 |
| `minor_gap` | 存在可见偏差, 但当前必要目标与明确要求仍保持 | 差异位置、方向及为何没有破坏必要目标 |
| `major_gap` | 目标缺失、必要表现或关系被破坏, 或违背明确要求 | 可见差异及具体受影响的目标/要求 |
| `uncertain` | 本项在范围内, 但材料不足或固定标准内的证据歧义影响判断 | 无法判断的具体内容与原因 |
| `not_applicable` | 绑定中本项没有必查内容, 且已经明确排除理由 | 引用固定排除依据, 不能依据候选缺项重新排除 |

有必查内容的指标只能使用前四种状态. `uncertain` 不能记成 `match`, 必查内容缺图、缺坐标或缺背景也不能改成 `not_applicable`. 同一指标同时存在确定差异和材料不足时, 状态保留已确认的最高差异等级, 另在 `unassessed` 中登记未知部分. 必须改变绑定才能消解的目标冲突按停止流程处理, 不通过 `uncertain` 改写原范围.

### 3.1 重大与轻微的锚点

| 指标 | 重大差异示例 | 轻微差异示例 |
| --- | --- | --- |
| 目标完整性 | 指定亮带完全缺失; 整图缺少主要对象 | 必要结构完整, 仅有不承担目标作用的小装饰差异 |
| 位置与比例 | 两个圆的位置关系改变, 原本交叠变为分离 | 构图和关键间距保持, 存在小幅可见偏移且未违反明确容差 |
| 形状与边界 | 必要开口消失, 圆环变为实心面 | 关键轮廓与开口保持, 局部曲率有轻微偏差 |
| 色彩与明暗 | 主色或主要亮暗方向错误, 改变目标表现 | 色场和层次保持, 个别区域略偏冷或偏亮 |
| 纹理与表面细节 | 平滑表面变成主导画面的颗粒噪声 | 纹理类型、方向和尺度基本保持, 少量细节强度有偏差 |
| 可见关系 | 前后顺序颠倒, 必要透显完全没有表现 | 主要关系保持, 接触处的过渡略有差别 |

这些是锚点, 不是脱离任务的固定答案. 重大问题始终表示本次必要目标或明确要求被破坏, 层级不会自动改变这一语义. 局部任务明确要求“小孔”时, 小孔缺失即使面积很小也可能是重大问题; 若同一要求在整图中仍适用, 不能因整图范围更大就降级. 需要精确色值或几何容差证明但没有测量时保留无法判断, 不凭目测编造精确误差.

轻微问题可以共同形成明显的整体偏差, 但不能按条数自动升级. 确有整体影响时, 将共同造成该影响的差异合并为一条 `major` 问题, 保留各位置的具体比较依据和一个主要指标, 移除被它覆盖的重复问题条目. 独立的轻微问题可以保留. 仅在总结中声称“整体严重”不会改变派生结论, 也不能凭“轻微项超过三条”判失败.

## 4. 问题证据怎么写

每个问题至少含 `id`、主要 `dimension`、`region`、`reference_observation`、`rendered_observation`、`severity` 和 `impact`.

示例: “前圆右侧外缘; 参考亮边较窄且逐渐淡出; 渲染亮边更宽且形成硬白条; `major`; 本轮目标就是窄而柔和的边缘, 当前表现没有达到该目标.”

避免仅写“相似度不足”“材质不真实”或“效果不够好”. 对可见表现作具体比较, 而不是替生成者诊断算法. 未测量时不用百分比、像素数或精确色差包装目测印象.

保留已经正确的部分可写入各项 `match` 或 `minor_gap` 的依据, 不为首版增加另一套修订计划. 生成侧后续如何使用报告另行设计.

## 5. 怎样汇总成结论

报告绑定实际 `BoundReviewCriteria`, 包含六项 `dimensions`、去重后的 `issues` 和 `unassessed` 未评项. 每个未评项记录涉及指标、具体内容与原因. `limitations` 记录不影响本轮必要检查的范围限制, 例如本次只评静态帧; 不能把必要未评项藏在这里.

模型判断具体差异等级, 程序根据有效条目派生结论:

```text
存在明确的 major 问题:
    verdict = needs_revision
否则, 存在范围内必要未评项:
    verdict = inconclusive
否则:
    verdict = no_major_issue_observed
```

| 场景 | 总体结论 | 保留信息 |
| --- | --- | --- |
| 其他五项很好, 主要对象缺失 | `needs_revision` | 其他项的良好表现不能抵消重大问题 |
| 已确认重大问题, 同时有必要项目无法判断 | `needs_revision` | 未评项保留, 表示仍未完整覆盖 |
| 只有轻微偏差, 所有范围内必要检查均可完成 | `no_major_issue_observed` | 轻微问题仍展示, 不是完全一致 |
| 未确认重大问题, 但必要关系因缺少背景无法评价 | `inconclusive` | 缺失材料与受影响目标 |
| 只有范围外的差异 | 按范围内结果判断 | 范围外差异不作为扣分证据 |

合同校验采用以下规则, 不由模型通过总结文字改写:

- 六个固定指标 ID 恰出现一次. 绑定必须至少有一项非空必查内容; 没有有效检查目标的绑定在模型调用前拒绝, 六项全部 `not_applicable` 不能成为合法报告.
- 有绑定必查内容的维度不得为 `not_applicable`; 无必查内容的维度只能保留 `not_applicable` 与固定排除理由, 不能引入问题或必要未评项.
- 问题与未评项 ID 在各自列表内唯一, 引用必须存在. 每个问题必须被其主要指标引用; 每个未评项必须被对应指标引用, 不接受游离条目.
- 一个指标引用已确认问题时, 状态取关联问题的最高严重性. 同一问题只有确实影响另一个指标时才交叉引用, 不能为展示而复制引用.
- 没有已确认问题但有必要未评项时, 状态为 `uncertain`. 存在已确认问题时可同时引用未评项, 状态保留差异等级, 总体结论仍考虑这些未知内容.
- `match` 与 `not_applicable` 不得关联问题或必要未评项. 自由文本检查点是否被理解、范围内子项是否遗漏仍需人工校准, 程序校验通过不能证明全部语义已经核对.

维度提交状态必须完全等于绑定和引用条目派生的状态: 无必查项为 `not_applicable`; 有问题为最高差异等级; 无问题但有未评项为 `uncertain`; 其余为 `match`. 状态不一致时拒绝提交, 不静默覆盖. 这也禁止没有问题或未评项依据的 `major_gap`、`minor_gap` 或 `uncertain`.

程序派生结论只能保证逻辑一致, 不能保证模型的视觉判断正确. 允许模型给出总结文字, 但总结不得覆盖派生结论. `completed` 只表示报告已经交付; `no_major_issue_observed` 也不等于用户验收、整图通过或自动停止授权.

## 6. 指标应用示例

以下是规则示例, 未使用真实模型产生, 不属于验证结果.

| 任务 | 参考与候选 | 应有判断 | 要防止的错误 |
| --- | --- | --- | --- |
| 局部: 只评圆环轮廓 | 轮廓相符, 候选外围背景颜色不同 | 范围内 `shape=match`, 外围背景不扣分 | 把局部任务扩大成整图比较 |
| 局部: 评整个圆形元素 | 轮廓相符, 但元素内部主色与参考相反 | 按元素绑定检查 `color`, 主色破坏目标时为重大问题 | 将特征模板的颜色排除规则沿用到元素模板 |
| 局部: 评圆环开口 | 候选的小开口被填平 | `shape=major_gap`, `needs_revision` | 因开口面积小而判轻微 |
| 局部: 评元素绝对位置 | 候选物体偏右, 后处理分别居中裁剪 | 若已保留坐标则报告偏移; 缺坐标则无法证明位置 | 用裁剪后的重合掩盖错位 |
| 局部: 评磨砂透显 | 参考叠在彩色背景, 候选只有黑底孤立形状 | 形状可评, 必要透显为未评项, 无其他重大问题时 `inconclusive` | 把上下文缺失判成方法失败或通过 |
| 整图: 复现两圆交叠 | 两个圆各自外观近似, 但被放成互不接触 | `layout` 的重大问题, `relations` 可引用同一问题 | 平均局部结果得到整图通过 |
| 整图: 复现平滑色场 | 候选出现明显密集噪点 | `surface` 按实际影响分级 | 因参考无纹理把表面指标排除 |
| 任意范围: 同图且要求一致 | 两张实际图片相同, 目标材料完整 | 没有问题时可提交空 `issues`, 结论无主要问题 | 为满足条数编造差异 |

## 7. 怎样验证这些指标有效

视觉维度衡量候选, 下表衡量评审 Agent. 人工参照使用相同图片、模板和绑定, 按 `feature`、`element`、`scene` 分组报告. 模板或绑定改变后的两次结论不能直接用作候选改进证据. 人工先标注再看 Agent 结论, 争议项保留复核, 不把单个人判断当作绝对真值.

| 指标 | 计算口径 | 主要风险 |
| --- | --- | --- |
| 问题精确率 | 正确匹配的去重问题数 / 模型报告的问题数 | 凭空指出差异、方向错误、越界评审 |
| 重大问题召回率 | 被正确识别并标为重大问题的人工重大问题数 / 人工重大问题数 | 漏报或把必要失败降为轻微 |
| 错误放行率 | 人工有重大问题却得到 `no_major_issue_observed` 的案例数 / 人工有重大问题的案例数 | 错误建议结束本轮修改 |
| 无重大问题误拒率 | 人工无重大问题却得到 `needs_revision` 的案例数 / 人工无重大问题的案例数 | 对可用结果造成不必要返工 |
| 无法判断率 | `inconclusive` 合法报告数 / 合法报告数 | 过度弃权; 需结合材料是否确实不足解释 |
| 范围遵守率 | 没有把范围外内容记作问题的合法报告数 / 合法报告数 | 局部与整图规则混用 |
| 完成率与成本 | 正式报告数 / 启动数, 另报实际调用、耗时、可得费用 | 隐去运行失败或额外调用成本 |

问题按目标、位置和差异方向一对一匹配, 不按用词完全相同匹配. 模型将同一问题拆成多条不能提高正确计数. 分母为零记为 N/A, 每项保留原始计数与样本数量. 若人工参照漏标真实问题, 更新参照版本后对全部方案统一重算.

补充检查同输入独立重复运行的结论和重大问题是否稳定. 稳定性不等于正确性, 重复同一图也不增加独立图像样本量. 少量样例先检验规则可用性, 不据此宣称普遍可靠.

首版不设总分、概率置信度或自动验收阈值. 后续只有在代表性图像上完成误报、漏报和弃权校准后, 才讨论是否增加数值度量和停止策略; 规则开发样例与最终评估样例按参考图分开.
