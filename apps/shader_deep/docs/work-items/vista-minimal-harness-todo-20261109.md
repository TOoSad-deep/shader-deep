## 首版范围

做一套小型公共视觉记忆能力, 先接入现有单任务生成流程, 让 Agent 能主动回看历史候选. 以本轮参考图和候选 PNG 为主要材料, 关联已有代码及业务记录; 后续分析与调参可复用同一能力.

复用现有运行目录、候选保存、图像处理和 Deep Agents 执行能力. 当前缺口主要是可发现的材料索引、主动回看工具以及精简的图像选材, 围绕这三个缺口实现.

## 已确认的首版数据设计

以下为讨论确认的设计, 尚未实施; 是本项目的选择, 不代表 VISTA 规定的文件格式.

### 集中材料索引

- 使用 `memory/index.json`, 外层保存 `version`、`run_id` 和 `materials`; `materials` 以材料 ID 为键, 条目内不重复保存 `id`.
- 每条材料包含 `kind`、`label`、`path`、`sha256`、`source`; 派生材料额外包含 `derived_from`.
- 材料路径统一相对于运行目录. 原图、候选 PNG 和 GLSL 复用已有文件位置, 不为建立索引重复复制已有材料.
- 不使用 `catalog.json + materials/<id>.json`. 简短目录从索引生成, 不单独维护.
- 列材料工具只返回简短目录; 读材料工具按 ID 返回实际内容和必要来源. 已知 ID 时可以直接读取, 渐进式披露由工具返回范围实现.

### 来源 `source`

- `type` 和 `task_id` 必填, 其余字段按来源类型填写.
- `type: input`: 任务输入, 使用 `role` 表达输入用途, 例如 `reference`.
- `type: output`: 工具产物, 使用 `operation` 记录产生它的操作; 有关联候选时填写 `candidate_id`.
- `type: derived`: 派生材料, 使用 `operation` 记录产生它的操作; 具体来源材料与变换参数由 `derived_from` 表达.
- 公共材料不强制绑定候选. `source` 保存追溯入口, 不复制已有业务记录中的目标、渲染条件、状态或观察结论.
- 导入旧材料时需要保留原运行和原材料身份; 具体字段后续讨论, 不能只记录本轮任务.

### 派生关系 `derived_from`

- 首版先支持裁剪: 保存 `material_id`、`operation: crop` 和 `region: {x, y, width, height}`.
- `material_id` 引用直接来源材料. 对裁剪图继续裁剪时引用该裁剪图, 沿引用链追溯原图.
- 区域相对于直接来源图像, 左上角为原点, 单位为整数像素; 范围为 `[x, x + width)`、`[y, y + height)`, 尺寸必须为正且区域不能越界.
- 保存的裁剪图保留来源区域的原始像素. 显示缩放与存储裁剪分开, 不改写来源坐标.
- `source.operation` 表示产生材料的工具操作, 例如 `inspect`; `derived_from.operation` 表示实际图像变换, 例如 `crop`.
- 其他变换在出现实际需求时再扩展.

### 材料身份、内容校验与重复处理

- 材料 ID 由程序分配, 如 `m0001`, 在本运行内唯一且不变; 跨运行定位使用 `run_id + material_id`.
- `sha256` 对实际保存的文件字节计算, 用于内容校验, 不代替材料 ID. 登记后不能原地替换内容, 内容变化应登记为新材料.
- 回读时文件哈希不符应明确返回错误, 不将变化后的内容作为原材料提供.
- 再次读取同一材料不新增记录. 同一任务对同一来源做相同区域裁剪时复用已有派生材料.
- 不同渲染即便得到字节相同的图片也分别登记, 保留各自候选来源. 视觉相似但文件字节不同不自动视为同一材料.
- 首版仅复用明确的重复操作, 不做跨材料自动合并或文件去重.

### 内容类别、名称与文件位置

- `kind` 首版使用 `image`、`code`、`text`、`json`, 分别表示图像、源代码、普通文本或 Markdown、结构化 JSON 资料. 程序据此选择读取方式; 图像的具体用途和来源由其他字段表达.
- `label` 由程序根据已知信息生成简短名称, 如任务参考图、候选 2 的预览、候选 2 的局部及坐标. 不额外调用模型生成标签, 不在标签中写入效果判断.
- 已有修改意图和观察备注可在列目录时从关联记录中补充展示, 不复制进标签.
- `path` 相对于运行目录, 复用已有文件位置; 新派生图片放入 `memory/derived/`. 外部输入先捕获到运行目录再登记.
- 解析后的实际路径必须位于运行目录内. 文件缺失时明确返回错误, 不悄悄改读其他文件.

### 列材料工具

- 暂名 `list_materials`. 可选输入为 `kind`、`limit`、`cursor`; 省略 `kind` 时列出全部类别, `limit` 默认 20, 首次读取不需要游标.
- 当前运行及允许访问的材料范围由程序绑定, 不接受模型提供的任意目录.
- 返回 `materials` 和 `next_cursor`. 每项包含 `id`、`kind`、`label`, 有关联时附带 `candidate_id` 或 `derived_from_id`; 无下一页时 `next_cursor` 为 null.
- 按登记顺序排列, 分页时新增材料不导致已有条目移位. 首版不增加排序和复杂搜索选项.
- 默认不返回路径、哈希、完整来源、代码正文或图片. 已有观察备注可以附带简短摘录, 并标明其为观察记录.
- 列目录不代表材料内容已经进入模型请求, 不赋予预览呈现资格. 已知 ID 时可以直接调用读材料工具.

### 读材料工具

- 暂名 `read_materials`, 输入 `items` 数组; 每项包含 `id` 和可选 `region: {x, y, width, height}`. 已知 ID 时可直接调用.
- 仅提供 ID 时读取完整材料: 图像返回实际图像, 代码、文本及 JSON 返回正文. `region` 仅适用于图像, 裁剪后保存并登记派生材料, 已有相同裁剪则复用.
- 按请求顺序返回, 每份内容附明确标签; 多图以独立图片返回, 首版不要求生成拼接图.
- 每项说明请求材料 ID、返回材料 ID、名称、必要来源; 图像还说明完整或局部视图及尺寸, 局部包含来源材料和区域. 完整读取的请求与返回 ID 相同, 裁剪返回派生材料 ID.
- 不自动展开关联材料, 读取预览不附带代码; 需要时显式请求对应材料 ID.
- 错误按项返回, 某项失败不阻止其他合法项读取. 不静默替换材料、不自动修正越界区域、不将截断正文当作完整内容返回.

### 回看材料的上下文保留

- 磁盘原件继续保留. 默认材料持续提供, 主动回看的图片或正文只供紧接着的一轮模型判断使用, 同批读取的材料一起呈现; 之后收回为引用, 需要时再次读取.
- 后续历史保留工具调用与响应配对、材料 ID、区域及成功或失败状态; 模型自身的观察文字继续保留, 不额外调用模型生成摘要.
- 首版不增加固定材料或释放材料工具. 连续多轮需要同一旧材料时可能重复读取, 是否延长保留时间由实测决定.
- 按最终发送请求验证旧图和正文载荷确实退出历史, 并避免同一材料在默认上下文与回看结果中重复注入.
- 网络重试属于同一逻辑轮次, 保留相同回看内容.

### 读取限制与调用预算

- 每轮额外读取材料初始上限为 4 份, 默认材料另计; 同轮多次读材料调用共用额度. 整图、裁剪图、代码各算一份, 超出部分明确返回预算不足, 不静默丢弃.
- 图像检查尺寸与文件大小, 文本检查正文长度; 具体阈值实施时根据现有样例和模型输入限制配置. 超限返回材料 ID、实际大小与限制, 不影响材料保存.
- 超限图像可以改读局部, 不悄悄缩放后仍称原始尺寸; 超限文本明确报错, 不静默截断, 频繁出现过大资料时再补分段读取.
- `max_attempts` 与 `max_model_calls` 分别配置渲染尝试次数和模型判断轮次, 不再将后者固定为前者加 2. 读取不消耗渲染次数, 读取后的模型判断消耗模型轮次; 每轮告知剩余预算.
- 首版不另加记忆调用总次数预算. 每轮 4 份等数值为可调整的初始配置, 不是永久固定的模块契约.

### 默认上下文与候选选择

- 每轮持续提供任务目标、约束、渲染条件的简短文本及参考整图. 默认工作候选为最新成功候选, 提供整图及代码; 尚无新成功候选时使用已有基线.
- 最近一次渲染失败的错误与失败代码供下一轮修正, 之后按需回读. 主动回看材料沿用仅在紧接着一轮展开的规则.
- 记忆入口包含材料数量、读取方式及当前展示材料 ID, 不默认附带完整历史目录. 每次渲染返回新材料 ID, 查找旧版本时调用列材料工具.
- 最新成功候选不代表最佳候选. 最终允许选择本次会话中符合资格的旧候选.
- 最终可选候选必须在本次会话成功渲染, 且完整预览实际进入后续模型请求. 目录、代码及局部裁剪不替代完整预览.
- 已呈现整图的候选退出默认上下文后仍保留选择资格, 结束前不强制再次回看. 同批调用刚渲染出的候选必须经过下一次模型请求呈现才能选择.
- 最终交付读取所选候选对应的实际代码文件.

### 记忆写入触发

- 写入由程序在任务材料保存成功后自动触发, 不要求模型决定是否保留, 也不在每轮模型调用时重复登记.
- 任务输入准备完成: 登记本轮已捕获的参考图、基线及报告资料. 已有文件仅登记, 不重复保存.
- 工具产生内容: GLSL 保存后登记代码; 渲染成功且 PNG 保存后登记图像; 渲染失败时保留代码并关联已保存的错误记录, 不创建不存在的预览.
- 回看产生派生内容: 裁剪图保存后登记来源与区域; 相同裁剪已有记录时复用.
- 普通列目录、回读原图或代码不新增材料. 本轮实际呈现内容由呈现记录管理.
- 观察与结论先复用已有结果提交记录; 模型自由文本观察留在模型历史中, 不自动转为结构化记忆. 独立的主动笔记写入能力未纳入首版.
