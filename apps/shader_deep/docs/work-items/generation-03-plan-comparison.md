# 03 多方案比较实施方案

日期: 2026-10-03.

## 状态与目标

状态: 待实施. 本文只规定第三个实施分支, 未创建分支或调用模型. 开始前按 02 的实际接口、运行目录和结束状态复核本方案, 有差异先更新本文.

目标: 对同一元素的两套显式方案顺序执行独立生成, 在同图、同目标、同基线和同渲染条件下保留结果, 交给用户比较并选择. 一项失败不能抹去已有产物或阻止另一项正常执行.

共同目录和契约以[生成整体架构](../generation-architecture.md)为准; 本文只补比较阶段的装配、索引和选择步骤.

## 最小输入与输出

输入包含同一固定报告及原图、同一元素、两组草图 ID 与可选备选索引、用户目标、可选基线、尺寸、时间和每项执行额度. 模型配置也保持一致, 便于用户解释差异.

共同输入只捕获一次, 两项从同一份固定材料解析各自选择. 无基线时两项均无基线; 第二项不能隐式采用第一项产出的代码. 两项有独立任务、会话历史、计数和运行目录.

最小比较记录保存共同条件, 以及每项的显示名称、方案来源、运行目录、结束原因、已选候选和可用预览路径. 必要时只定义一个比较记录和一个条目类型, 不建立通用实验平台的数据模型.

输出为比较目录中的 `comparison.json` 和 `README.md`. 前者索引各子运行及共同条件, 后者提供方案说明、代码与预览导航. 候选正文、失败日志和实际 GLSL 仍由各 `run-*` 负责保存, 不复制为第二套状态账本.

比较索引中的用户选择初始为空. 子运行内部选中了候选只表示生成结束, 不表示用户已经选定比较胜者或接受视觉效果.

## 顺序实施步骤与完成条件

### 1. 固定共同输入并解析两项选择

复用 01/02 的报告读取和捕获能力, 在启动第一项模型前确定共同材料、目标与基线. 仅为两个独立任务分别绑定显式方案; 无效草图或引用沿既有输入错误返回.

完成条件: 两项任务可追溯到同一参考图、报告身份、目标、基线和渲染配置, 各自的有效选择清晰且不相互覆盖.

### 2. 顺序调用现有单方案闭环

比较工作流依次调用 02 的内部执行能力, 每项使用自己的运行目录和额度. 一项返回受阻、耗尽或运行失败时登记该项结果并继续下一项, 不扩大单项重试额度.

对执行入口会抛出的运行异常, 在比较边界保存失败原因和已有目录, 再继续下一项. 用户取消或键盘中断结束整批, 不作为单项失败继续派发. 输入准备整体失败时直接报告输入错误, 不生成两条虚假的执行结果.

完成条件: 一项失败后另一项仍可产出结果; 失败项的代码、错误与结束原因保留. 第二项的上下文没有自动加入第一项候选或自检结论.

### 3. 发布可核对的比较索引

两项均结束后写入比较索引与预览导航. 展示实际共同条件, 区分成功选择、受阻和失败, 可用预览指向真实子运行文件. 没有选中候选的条目明确标注未完成, 不制造预览或默认获胜项.

完成条件: 用户能从同一入口打开两项实际产物, 找到各自方案来源和停止原因, 无需阅读模型完整历史即可开始比较.

### 4. 保存人工选择并完成一个真实样例

用户查看预览后, 可明确指定一项及其中已选候选, 也可暂不选择. 用一个简单更新入口将该选择及可选理由写回比较索引; 选择只接受当前比较条目实际拥有的已选候选. 不改写子运行结果, 不自动启动后续整图生成.

完成条件: 对同一目标完成一次两套方案的实际比较, 如实记录程序结果、模型自检与用户选择. 用户未选择时仍可交付完整比较材料, 不能宣称已确定最佳方案.

## 最小必要验证

- 复用单方案夹具, 用一个两项案例检查共同条件一致、有效方案分别进入对应请求, 以及两个结果都有可访问的索引.
- 用一个单项失败案例验证另一项仍执行且失败记录保留; 在同一案例检查未完成项不会被写成默认选择.
- 对人工选择检查有效引用能保存并重新读取、无效候选被拒绝, 且原子运行结果保持原值; 不测试内部 helper 调用顺序.
- 分支收口在应用目录执行 `make test`、`make lint` 和 `make repository_check`. 改动图像装配、渲染或资源生命周期时执行 `make integration_test`, 复用现有浏览器案例.
- 明确图片、模型和使用条件后做一次真实两方案比较. 自动检查只证明执行与产物链路, 视觉偏好由用户给出, 不新增评分矩阵.

## 完成与不纳入

本分支完成意味着两项独立试验、失败保留、比较导航和人工选择记录可用. 不要求某一方案必然达到视觉目标, 不将未获用户选择视为执行器故障.

不纳入自动评分 Agent、自动淘汰与重跑、参数搜索、并行队列、调度服务、跨批次排行榜和崩溃恢复. 用户要求更换方案或目标时新建比较, 不重写旧试验.
