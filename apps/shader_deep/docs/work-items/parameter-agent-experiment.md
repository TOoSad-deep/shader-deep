本文按实施阶段保留记录. 当前工具入口及使用方式见[应用 README](../../README.md#独立调参实验); 早期 const 替换和单工具逐次渲染方案已被后面的常驻双工具方案替代.

## 第一版范围

调用方指定固定 Shader、可修改的 uniform 参数名称、初值与数值范围, Agent 仅选择这些参数的新值. 实验入口为 `experiments/parameter_agent.py`, 工具为 `experiments/parameter_tool.py`; 通过可选的关键字参数 `render_tool` 接入, 不需要主 Agent. 使用示例见 [README](../../README.md#独立调参实验).

按用户确认切换为独立的 `uniform float NAME;` 声明, 移除了替换 const 数值的逻辑. 每项参数配置必须提供 `min/max/initial`, 每次未指定的参数使用 `initial`, 不累积前次修改. 工具冻结源码及配置, 校验白名单、闭区间和有限数值, 浏览器通过 `gl.uniform1f` 赋值. 尺寸、时间、输出目录及预算由现有 `GenerationOptions` 固定, 默认最多三次, 渲染失败也消耗次数. 每次尝试保存固定源码、含完整参数快照的结果 JSON 和成功时的 PNG, 图像直接进入工具响应. 复现时须同时使用源码、完整参数及渲染条件.

`WebGL2Renderer.render` 新增可选的关键字参数 `uniforms=`, 不改变旧位置参数. Python 拒绝覆盖 `iTime/iResolution`; 浏览器拒绝不存在、被优化掉或类型不匹配的 uniform, 原始错误阶段为 `uniform`. 渲染器继续独立于 Agent 框架.
