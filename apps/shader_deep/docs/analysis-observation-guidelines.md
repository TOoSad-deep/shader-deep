# E/F/R 观察粒度规范

## 核心定义

> F 保存目标的可见外观或规则重复群。
> R 保存参与项之间必须共同保持的关键约束。

| 类型 | 记录单位 | 描述重点 |
| --- | --- | --- |
| 元素 E | 一个完整分析对象, 或职责一致的对象群 | 自身范围、主要外观与场景角色 |
| 特征 F | 一处可辨认的现象，或一个有分布规律的群体 | 位置、形状、颜色、明暗、软硬与内部变化 |
| 关系 R | 一类重要的相对约束或交互现象 | 参与项，以及它们需要怎样配合 |
| 机制 M | 实现观察目标的候选方法 | 怎样构造，不冒充图中已证实的成因 |

只登记当前目标复现必需的现象。
辅助背景可作为上下文，不自动扩成 F/R。
物体名称、材质印象和实现术语不能代替具体观察。
拆分应做到归属清楚、目的明确、信息完整、没有重复目标。
特征和关系的数量随图像内容变化。

## 全图中的元素与上下文

- 先确定完整分析目标, 再把具有独立外观与场景角色的主体登记为 E; 一个角色可以在同一任务中分析多个 E.
- 同类重复单元共同构成主体群时, 可以合为一个 E, 在 F 中描述单件形态与群体分布. 颜色不同或实例数量本身不足以拆成多个 E.
- 场景角色明显不同的主体可以分别建 E, 例如提供底层内容的彩色圆与形成覆盖区域的浅灰圆.
- 纯色底色可作为上下文; 网格等具有关键结构并参与交互的背景, 在全图分析中可以登记为 E.
- 依附主体的柔影、亮带等先作为 F. 效果的交叠区域可作为 R 的作用范围, 不自动再建 E.

五图中的完整拆分见[全图校准样例](analysis-observation-examples.md). 这些规则组织视觉对象, 不规定为每个 E 新建一个 Agent.

## 特征何时拆开，何时合并

| 情况 | 默认处理 | 已确认的参考 |
| --- | --- | --- |
| 同一处现象具有多种属性 | 在同一 F 中描述，保留属性差异 | 一段亮带的白色核心与柔和过渡合记 |
| 不同局部具有清楚的位置与外观差异 | 可分别建 F，各自承担观察目标 | 左上与右下亮带分开 |
| 多个小单元共同形成规则群体 | 按群建 F，写清分布规律 | Windows 左侧碎片群合记 |
| 群体内有必须单独保留的特殊局部 | 指出其独立价值后，再讨论拆出 | 属于新图的边界判断，不逐个实例自动拆分 |

合记重复群时，保留颜色、行列、数量或密度线索。
同时保留尺寸、间距、方向与空间变化中实际可见的部分。
不要求每个群体具备所有这些属性。

采用相同机制，不是合并 F 的充分理由。
能够单独调节参数，也不是拆分 F 的充分理由。
先看是否形成不同的可见目标，再决定条目边界。

同一属性在不同图中，不必采用相同拆法。
粉色圆形先把轮廓与窄边沿合记。
网格图则把轮廓与边缘亮暗分别记录。
后者的边缘明暗承担了独立的材质外观判断。

## 关系按约束含义分组

| 情况 | 默认处理 | 已确认的参考 |
| --- | --- | --- |
| 多个参与项需要满足同类配合 | 可以合为一条 R | 两段亮带共同顺着主体轮廓展开 |
| 同一组参与项具有不同类型的约束 | 可以拆成多条 R | 前后覆盖位置与交叠区外观分开 |
| 多种变化共同描述同一局部交互 | 可以在同一 R 内保留 | 交叠区的模糊与颜色变化合记 |
| 两项观察只是同时存在 | 不自动新增 R | 圆形、亮带、柔影共现本身不构成约束 |

一条 R 可以涉及两个以上参与项。
参与项相同，也不要求所有约束合成一条 R。
不为全部 F 的两两组合自动登记关系。

先比较视觉判断目的，再考虑是否分别检查。
能够分别出错或调参，只是拆分线索。
它不要求把同一局部交互拆到每个属性。

## F 与 R 的主要归属

| 观察内容 | 主要归属 | 记录方式 |
| --- | --- | --- |
| 目标自身的一处外观 | F | 写清现象与定位 |
| 相对位置只用于识别某处观察 | 通常留在 F | 左上亮带、下方柔影可直接定位 |
| 必须比较参与项才能说清的配合 | R | 写清参与项与共同约束 |
| 覆盖后背景发生的可见变化 | R | 描述交互范围及背景如何变化 |
| 已有具体观察的概括词 | 沿用原记录 | 不再把“雾感”作为重复的额外目标 |

同一现象保留一个主要记录位置。
F 可以保留定位信息，R 补充必要的共同约束。
这样不要求删掉有助于阅读的名称和指代。
但不能把相同一句观察重复列为两个复现目标。

若概括词背后有独立可见的内容，再补具体 F/R。
例如内部另有独立色场，就不只是格线变化的概括。

高斯、折射、模糊采样属于机制候选。
观察中应先写亮带、格线变化或交叠外观。
看不清的位移、尺寸或成因保留为未知项。

## 已确认例子作为后续锚点

完整全图拆分见[五图校准样例](analysis-observation-examples.md).
| 例子 | 已确认的记录方式 | 适用范围 |
| --- | --- | --- |
| 粉色圆形 | 五项 F：轮廓边沿、主体色场、两段亮带、外部柔影 | 该图的特征拆分起点 |
| 粉色圆形的亮带配合 | 一条 R 共同关联轮廓与两段亮带 | 两段亮带顺着邻近轮廓延展 |
| Windows 左侧碎片 | 整个碎片群作为一项 F | 群体内部仍描述各色小块的分布 |
| 两圆交叠 | 覆盖位置一条 R，模糊与颜色变化一条 R | 只确认关系边界，未冻结完整 F 清单 |
| 网格图右上大形状 | 轮廓、边缘明暗两项 F；网格变化与雾感一条 R | 左下小圆不在这次展开范围内 |

这些例子用于校准判断，不作为固定条数模板。
其他图中的必要现象仍需据图判断。
跨对象关系还需满足实际任务的输入与引用合同。
本规范不扩大当前分析角色可访问的对象范围。

## 后续分析与提交前复查

1. 固定目标与上下文.
2. 列出直接可见的必要现象.
3. 确定主要归属为 F 或 R.
4. 按视觉判断目的拆合.
5. 去重并保留内部变化.
6. 对照已确认例子复查.

提交前检查以下五项。

| 检查项 | 通过标准 |
| --- | --- |
| 可定位 | 能指出观察范围，并说明具体看到什么 |
| 有必要性 | 删除该记录会遗漏必要的视觉目标或约束 |
| 边界合适 | 每项承担清楚的目的，未按每个属性或重复实例机械拆分 |
| 无重复目标 | 概括与细节没有在 F/R 中重复承担覆盖义务 |
| 信息保留 | 合并后仍保留关键位置、形态与分布差异 |

程序校验另行负责结构与引用是否合法。
它不能证明这次视觉拆分合理或结论正确。
规范通过分析提示和报告审阅使用，无需新增粒度字段。

## 可直接复用的分析提示段

以下是供后续分析使用的提示文本。
尚未写入当前分析角色的运行提示。

```text
分析参考图时，按以下口径组织特征 F 与关系 R。

先固定当前目标与必要上下文，只登记复现必需的可见现象。
E 表示完整分析对象或职责一致的对象群，元素数量不决定 Agent 数量。
同类重复群可合为一个 E，角色不同的主体可分别建 E。
纯色底色可作为上下文，具有关键结构并参与交互的背景可登记为 E。
F 记录一处可辨认的外观，或一个有分布规律的重复群。
一处现象的形状、颜色、明暗与软硬可在同一 F 内描述。
位置和外观差异明确的局部，可以分别建 F。
重复群按整体规律记录，保留内部颜色、尺寸与空间分布变化。
不因共享实现机制而强行合并 F，也不因参数可调就拆出新 F。

R 记录参与项之间必须共同保持的一类关键约束或交互现象。
同类配合可关联多个参与项，合为一条 R。
约束含义不同，即使参与项相同，也可以拆成不同 R。
同一局部交互的多种外观变化可以合记，不逐属性机械拆开。
共现或定位说明不自动产生 R，不对所有 F 两两建关系。

每个观察保留一个主要归属，避免在 F 与 R 中重复列为目标。
“雾感”等概括若没有新增具体观察，沿用已有交互记录。
直接描述看见的现象，把成因和实现方法留给机制候选。
无法确认的数量、位移、尺寸与成因保留为未知项。
只引用当前任务可见且合法的参与项，不补造对象身份。

提交前复查：可定位、有必要性、边界合适、无重复、细节保留。
没有固定的 F/R 数量，使用以下已确认例子校准边界。
粉色圆形：轮廓边沿、主体色场、左上亮带、右下亮带、外部柔影共五项 F。
两段亮带顺着主体轮廓展开的配合，合为一条 R。
Windows 左侧碎片群：整体为一项 F，内部保留各色小块的分布。
两圆交叠：覆盖位置一条 R，交叠区模糊与颜色变化一条 R。
网格图右上大形状：轮廓、边缘明暗两项 F，网格变化与雾感一条 R。
```
