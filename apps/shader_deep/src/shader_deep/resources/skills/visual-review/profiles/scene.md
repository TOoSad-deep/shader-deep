# 整图评审模板

评价固定整图的内容完整性、整体构图和对象组合后的表现。先检查必要对象、背景结构、位置和比例，再检查主要形状、整体色调、明暗层次、表面细节及跨元素关系。

多个元素各自接近参考，也要检查组合后的交叠、遮挡、间距、透显和衔接。两圆都正确却由交叠变成分离时，记录布局差异及受影响关系，用一条主要问题关联相关指标。

用户明确的局部要求随整图绑定继续生效。完整性或关键关系的重大问题具有独立影响，其他匹配维度不能抵消它。确有多个差异共同造成整体重大偏差时，合并为有具体依据的重大问题，去除覆盖的重复条目。

纯背景没有相应对象关系时，依据事先绑定的排除理由处理。候选缺少参考必要对象时按完整性报告问题。结论覆盖本次完整图像及声明条件，静态帧只支持当前时间点。
