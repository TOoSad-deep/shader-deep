# 局部备选与候选迁移

先用 choices 替换 default 中对应目标的整组方法，得到该备选的完整生效选择。未列出的目标继承默认值。

composition 省略时沿用默认全文。提供时，根据完整生效选择写出新的整图组织说明，保留仍然有效的定位、应用次数、输入依赖、共享结果、混合与裁切。

将该备选当作独立选中的整图方案回读。依据所选 M 与生效 composition 核对从输入到整图输出的安排，需要的组织信息集中在生效正文中。正文中的具名 M 与生效 choices 保持一致。

修改 F 后，检查同元素与跨元素的相关 R。需要联动调整的目标写入同一 choices。保持原选择的 R 仍需核对配合是否成立。

备选继承该 S.gaps。解决旧缺口、产生新必要缺口或实质改变缺口原因时，提交新的完整 S。

补充候选采用到方案前，阅读其 reason 和各 M.conditions。仍有效的组合限制落实到 composition，未解决的必要限制进入相应 S.gaps。核对后移除新版本中的重复 extra_candidates。

候选组合保留共同使用语义。来自不同来源的多个方法需要重新组织成完整 S，再检查依赖和缺口。候选索引保留所有来源用于回看。
