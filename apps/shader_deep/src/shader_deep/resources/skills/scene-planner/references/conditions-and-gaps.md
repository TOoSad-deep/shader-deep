# 条件来源与两类缺口

先区分方法内在前提、本次组合前提和当前必要缺口。

| 情况 | 表达位置 |
| --- | --- |
| 方法需要在邻近坐标重复取得底层颜色 | M.conditions |
| 简化备选适用于当前解析背景 | alternative.conditions |
| 当前方案没有安排底层颜色来源 | S.gaps |
| 位置、透明度或色值需要调准 | 生成阶段 |

条件声明后，在 S.composition 中说明实际输入来源和组合安排。例如先定义可重复求值的底层颜色函数，再在前景范围内柔化该函数。复核当前生成约束是否提供所需纹理或 Pass。

上游观察 gaps 原样继承。E 级或全图级缺口可能还没有 F/R 身份，其必要性继续影响全部 S。选择覆盖了现有 F/R 时，仍检查上游 gaps。

open_questions 作为待确认材料。确实缺少必要观察时，由观察层用 gap 表达，并通过修订后的观察版本更新。

S.gaps 引用受影响的必要 F/R 并说明具体问题。已有方法映射且条件来源尚未解决时，两者同时保留。
