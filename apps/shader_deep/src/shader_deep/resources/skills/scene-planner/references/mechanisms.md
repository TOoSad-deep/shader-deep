# 方法粒度与输入组织

一个方法应让生成者知道构造动作、输入、输出和主要控制因素。

同一圆形距离可同时提供内部遮罩和窄边沿。调整位置、半径或应用次数时，继续使用同一 M，在 S 中安排每次应用。

具有独立替换价值的操作可拆开。例如区域遮罩、底层颜色柔化、透显混合各自具有明确输入和输出，可以独立说明。普通乘法和插值放在所服务的方法内部。

M 的输入用自包含概念表达。S.composition 交代本图哪个结果提供该输入，以及何时共享或重复计算。default 记录直接承担目标的方法。独立中间结果至少在所服务的一处目标选择中登记。

R 可由已有方法的共同安排满足。核对参与项的相对位置、共同坐标、输入来源或混合范围，给出生成者能执行的组织说明。
