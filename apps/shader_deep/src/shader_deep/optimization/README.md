# 外置参数优化

`optimize_uniforms` 消费固定 GLSL、`ParameterSpec`、起始参数、参考 PNG 和可选目标/保护矩形。参考图和渲染使用同一个左上原点画布。白名单决定哪些参数能动，每个分量按合同范围限位。

一次会话编译一个 WebGL2 program。试验读回所需矩形的 RGBA，使用区域均值与相对 RGB/亮度差、颜色像素 L1 和 Sobel 梯度比较。保护区相对起点的逐像素显示颜色或透明度超出容差时拒绝该试验。低维使用自适应坐标搜索，高维使用固定种子拉丁超立方采样和 CMA-ES。

优化器导出起始 PNG 和有效改善时的胜出 PNG。中途多次刷新最低误差时，另选误差下降幅度最大的至多两个中间点，保存正式 PNG、有效参数、评估序号与误差。两种优化入口都能回读这些点，生成者可在看到其预览后选用。起始误差低于最小有效下降幅度时返回 `baseline_satisfied` 并停止搜索，仍由评审判断视觉质量。已搜索但找不到满足保护且误差有效下降的参数时返回 `structure_bottleneck`。最终交付由领域函数 `bake_uniforms` 将独立 uniform 声明替换为对应类型的常量。用于烘焙的声明支持 `uniform` 后的精度限定符，声明前的 `layout(...)` 等限定符需在提交参数化代码前移除。
