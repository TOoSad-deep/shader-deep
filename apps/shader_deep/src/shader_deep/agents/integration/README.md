# 整合子 Agent

本角色在独立探索结束后比较已有材料, 处理初稿反馈, 提出合并、保留或暂缓决定. 它不重新派发探索、不生成 Shader, 也不替用户选择唯一真实机制. 整轮编排见[应用架构](../../../../docs/architecture.md).

## 阅读入口与调用边界

- [agent.py](agent.py): `IntegrationSubagent` 的启动、身份和结果接口, 组合内部执行程序.
- [worker.py](worker.py): `IntegrationInput` / `IntegrationOutcome`、独立执行记录、进度回调与失败落盘.
- [stages.py](stages.py): 初稿复核、比较发现和阶段推进.
- [comparison.py](comparison.py): 固定范围比较、材料呈现与受控提交.
- [contracts.py](contracts.py)、[prompts.py](prompts.py): 比较提交契约与判断标准. 阶段特有契约和提示在 `stages.py` 中.

输入是业务快照、初稿版本、探索反馈、同轮受控库服务以及派发前已消耗调用数, 加上固定原图和配置. 不继承主角色聊天历史或修复草稿. 库服务仍是同轮统一写入入口, 不随业务快照复制出另一份权威库.

结果包含初稿版本、问题处置、比较记录、缺口、库版本和独立执行记录. 可变业务进度复制后通过回调交给协调器, 不把内部模型会话暴露给工作流.

## 阶段顺序

| 阶段 | 工具与材料 | 结束条件 |
| --- | --- | --- |
| 初稿反馈处理 | `review_outline`, 原图、初稿、问题及库材料 | 提出受限文字修订、驳回或暂缓; 没有问题则跳过 |
| 独立复核 | `verify_outline`, 原图、原文、修订和反馈 | 复核确认后才关闭相应问题; 提案本身不算解决 |
| 拥有者发现 | `plan_comparisons`, 特征/关系/草图目录 | 形成程序绑定的同类比较工作; 发现不等于已比较 |
| 拥有者比较 | `submit_integration`, 每组完整判断材料 | 按特征、关系、草图顺序执行 |
| 候选发现与比较 | 基于当前规范拥有者和候选材料 | 同一规范拥有者下比较机制及前提 |

每阶段只开放自己的提交工具与局部修复. 普通比较不发送原图、不开放测量或扩大范围工具. 所需完整目录或材料超出请求预算时保留缺口, 不截断后声称全量判断.

初稿修订仅限已存在元素的显著外观文字和已有关系描述. 元素身份、范围、实例与关系端点保持不变; 新增或拆分对象的需求应暂缓. 原始探索输入和报告保留.

## 三类比较结果

- **合并**: 在程序绑定的同类目标范围内提出合并, 后端继续校验归属、引用、呈现和版本. 外观特征合并保留全部候选, 不等于候选机制相同.
- **保留**: 明确保留未合并目标及不同机制, 不表示已证明所有候选都正确.
- **暂缓**: 说明具体缺口并暂缓整组; 不能同时提交本组的合并或保留操作.

实际修改经过[四库发布边界](../../domain/library/README.md). 新工作不能绕过材料实际呈现和版本校验, 也不能把目录中出现过的 ID 当作已读正文.

## 预算、失败与进度

角色计数从零开始, 但全局剩余额度扣除初稿已经消耗的调用. `max_main_calls=0` 仅取消累计总调用限制, 各阶段与工作仍有自己的上限; 剩余额度为零不能转换成无限制.

局部超限、无进展或无法判断时, 暂缓当前工作并继续额度允许的独立工作. 已安排项不自动反复重入. 总调用或阶段额度不足时记录未执行项.

`integration-subagent.json` 保存角色状态, `integration-work.json` 保存各工作结果. 每个检查点通过回调刷新主快照; 协调器按完整子角色进度替换旧记录, 不重复追加缺口. 异常和中断先保存已有进度再传播, 主工作流决定最终部分交付.

子角色结束不等于整轮完成. 失败探索任务、未覆盖元素和未解决问题仍由工作流检查; `completed` 不证明机制真实或视觉验收通过.

## 修改后如何验证

在 `apps/shader_deep/` 执行:

```sh
uv run --no-sync python -W error -m unittest tests.unit_tests.workflows.test_managed_integration tests.unit_tests.workflows.test_analysis_replay tests.unit_tests.workflows.test_integration_interrupt -q
make check
```

这些用例覆盖默认入口、冻结回放、预算、材料权限、进度及异常. 真实模型整合质量需要另定输入和评估范围, 不能用无网络测试结果替代.
