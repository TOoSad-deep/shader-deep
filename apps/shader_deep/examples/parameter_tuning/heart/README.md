# 心形 Shader 结构修复样例

[revision-0013-fixed.frag](revision-0013-fixed.frag) 是用户提供的 `revision-0013.frag` 的修复版, 使用 WebGL2 原生 `main()` 入口. 宿主提供 `u_resolution: vec2`、可选的 `u_time` 及文件头标注的 8 个 float 参数. 原文件未覆盖.

## 修复内容

- 用闭合边界的有符号距离替代原来的圆瓣/主体硬并集. 右半边由圆弧及三次 Bezier 曲线组成, 镜像得到左半边; 每段曲线各采样 32 个线段.
- 圆瓣和主体共享肩部位置与竖直切线, 消除两种独立宽度造成的接缝、台阶和凸起.
- 距离只取自有限边界线段. 尖端下方不再使用与横坐标无关的半平面距离, 消除横跨画布的红线.
- 三处降序 `smoothstep` 改为正序结果反转, 保持原有渐变方向及过渡宽度. 颜色常量和高光/背景公式保留.

这是轮廓表示的修复, 并非保证与参考图完全匹配的解. 有限线段会近似曲线, 不能当作解析曲线的精确距离; 未进行实时帧率基准测试.

## 参数接口与语义变化

参数名称、范围、默认值均沿用输入文件, 但轮廓控制经过协调, 旧参数组合不保证生成相同形状:

| 参数 | 修复版含义 |
| --- | --- |
| `u_xd` | 圆瓣偏移控制. 内部限制为不超过 `0.999 * u_r`, 保持两瓣相连; 超过该位置会饱和 |
| `u_r` | 圆瓣纵向半径. 横向与 `u_wmax` 协调缩放 |
| `u_yc` | 圆瓣中心与肩部的纵坐标 |
| `u_tip` | 闭合轮廓底尖的纵坐标 |
| `u_wmax` | 圆瓣和主体共享的整体最大半宽 |
| `u_fall` | 下半部曲线收窄强度, 越大越收窄; 不再是旧公式的幂指数 |
| `u_glow` | 原有背景辉光增益 |
| `u_hi` | 原有心形高光增益 |

只加载 GLSL 不会自动设置 uniform. 应从文件头参数表读取默认值, 或使用模型实验输出的 `final_parameters.json`.

## 验证与实测记录

真实 WebGL 遮罩检查覆盖默认值、6 个几何参数分别取上下限、全部几何参数同时取最小/最大, 合计 15 组. 检查画布两侧和尖端以下无多余覆盖、左右对称、阈值前景为单个连通区域; 同一检查能在修复前检测到横线. 这些样本检查不等于穷举连续参数域.

完整验证与真实模型 A/B 重测记录维护在[调参实验记录](../../../docs/work-items/parameter-agent-experiment.md). 图片、每次模型结束原因、实际参数提交及验证脚本保留于该记录指向的独立运行目录.
